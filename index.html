Today's CSS Lesson: Positioning

CSS positioning controls where elements appear on a webpage.

Static

The default position of HTML elements.

Relative

Moves an element relative to its normal position.

Absolute

Positions an element relative to its positioned parent.

Fixed

Keeps an element in the same place on the screen.

Sticky

Moves normally until it reaches a specified position.
