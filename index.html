What I Am Learning in CSS

I am learning how to style a webpage using CSS properties.

1. Display

Display helps arrange elements in a page.

Examples: block, inline, inline-block, and flex.

2. Position

Position helps control where an element appears. Examples: static, relative, absolute, fixed, and sticky.

3. Width and Height

Width controls how wide an element is.

Height controls how tall an element is.

4. Margin and Padding

Margin adds space outside an element.

Padding adds space inside an element.

5. Border

A border creates a line around an element.

6. Background

Background properties can change the color or add an image.

7. Font

Font properties control text style, size, and boldness.

8. Color

Color changes the color of text inside an element.

9. CSS Priority Order

CSS specificity helps decide which style applies when multiple rules target the same element.

IDs generally have higher specificity than classes, and classes generally have higher specificity than element selectors.
