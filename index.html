What I Am Learning in CSS

I am learning how to style a webpage using CSS properties.

1. Display

Display helps arrange elements on a page.

Examples: block, inline, inline-block, and flex.

2. Position

Position controls where an element appears. Examples: static, relative, absolute, fixed, and sticky.

3. Width and Height

Width controls how wide an element is.

Height controls how tall an element is.

4. Margin and Padding

Margin adds space outside an element.

Padding adds space inside an element.

5. Border

A border creates a line around an element.

6. Background

Background properties can change colors or add images.

7. Font

Font properties control text style, size, and boldness.

8. Color

The color property changes the text color.

9. CSS Priority Order

CSS specificity helps determine which style applies when multiple rules target the same element.

Generally, ID selectors have higher specificity than class selectors, and class selectors have higher specificity than element selectors.

Today's CSS Practice

10. Hover Effects

Hover effects change an element's appearance when the mouse pointer moves over it.

Try hovering over the navigation links above.

11. Transitions

Transitions make changes to colors and other CSS properties happen smoothly over time.

12. Keyboard Focus

Focus styles help users see which link is selected when navigating with a keyboard.

13. Outline

An outline highlights an element without taking up space like a border does.
